# dusfonts
A simple and elegant font previewer web application that allows users to view different fonts, copy their import links, and preview them in multiple sizes. It supports searching, dynamically loading fonts, and viewing them in a modal.

## Features

- **Font Preview**: See a preview of the font with sample text in multiple sizes (Small, Medium, Large).
- **Search Functionality**: Search for fonts by name to easily find the one you're looking for.
- **Copy Font Import**: Copy the import link for each font to use in your web projects.
- **Modal View**: View fonts in a full-screen modal with various sizes for better visibility.
- **Load More**: Load additional fonts with a button click for an extended list.
- **Responsive Design**: Works well on both desktop and mobile devices.

## Technologies Used

- **HTML**: Structuring the content and modal.
- **CSS**: Styling the UI, including the modal and font previews.
- **JavaScript**: Handling dynamic behaviors such as font preview, search, copy import, and modal functionality.
- **Google Fonts API**: Font styles are fetched from Google Fonts using `@import`.

## Installation

To use this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/beingdusmamud/dus-font.git
   ```
2. Navigate to the project folder:
   ```bash
   cd font-preview
   ```
3. Open `index.html` in your browser.

## Usage

### 1. **Font Preview**
   - Click on the **Preview** button next to any font to see how it looks in various sizes (Small, Medium, Large).

### 2. **Search Fonts**
   - Use the **search bar** to quickly find fonts by name.

### 3. **Copy Import Link**
   - Click on the **Copy Import** button to copy the Google Fonts import link for the selected font.

### 4. **Load More Fonts**
   - If you want to see more fonts, click on the **Load More** button to load additional font options.
